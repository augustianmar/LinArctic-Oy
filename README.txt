LinArctic bilingual website (English / Finnish)

Open index.html in a web browser. Use the EN / FI switch to change languages.
For hosting, upload index.html, fi.html, styles.css and script.js into the same directory.

Note: This is a standalone reconstruction of the existing design and copy because the GitHub integration did not permit writing or downloading repository assets. The original SVG logo is not included; a styled LinArctic wordmark is used instead. Contact information is intentionally pending.

UPDATED: The finalized LinArctic landscape logo has been added as linarctic-logo.png and appears in the header and footer of both languages.
